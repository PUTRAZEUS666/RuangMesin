# Ruang Mesin

Prototipe web sistem peminjaman alat Laboratorium Teknik Mesin. Dibuat dengan React dan Vite.

## Menjalankan aplikasi

Pastikan Node.js dan npm sudah terpasang, lalu jalankan dari folder proyek:

```bash
npm install
npm run dev
```

Buka URL lokal yang ditampilkan Vite di terminal.
